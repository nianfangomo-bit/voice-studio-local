# 从下载到你的第一段配音

声线工作室是装在 Windows 电脑上的本地配音工具。你可以用自己的录音训练一个声线，以后输入文字就能继续使用，不需要每次重新训练。

现在提供的是 **1.0.2-rc.1 测试候选版**。安装环境已经打包好了，但另一台电脑上的完整训练测试还没做完。愿意帮忙测试的话，请按下面的顺序来；用于重要项目之前，先用短文案试一次。

## 先下载对的文件

打开 [1.0.2-rc.1 下载页](https://github.com/nianfangomo-bit/voice-studio-local/releases/tag/v1.0.2-rc.1)，展开 Assets。

最省事的方法是下载并阅读 `DownloadOffline.ps1`，再让熟悉电脑的人或本机助手帮你运行。它会把本版本的安装文件下载到一起，并检查文件是否完整。不要全局关闭系统防护或更改执行策略。

如果手动下载，需要这几类文件：

- `VoiceStudio-Offline-Setup.exe`：安装程序。
- `offline-package.json`：安装清单，必须与安装程序放在一起。
- 文件名以 `.part001` 到 `.part025` 结尾的 **全部 25 个分卷**，缺一个都不能安装。
- `SHA256SUMS.txt`、`INSTALL.txt`、`ACCEPTANCE.json`：校验、安装说明和这版实际测过的内容。

不要点 GitHub 的 **Source code**。那是开发者看的源码，不是包含模型的安装包。也不要把旧版本分卷混进来，或单独解压 part001。

整包约 6.02 GiB。优先放到空间充足的非 C 盘，安装时建议至少留出 30 GB，训练还会额外占空间。包内已有 Python、GPT-SoVITS 和基础模型，不用你自己拼环境。电脑仍需要兼容的 Windows 64 位系统和 NVIDIA 驱动；有显卡不代表当前驱动一定可用。

## 安装和打开

把安装程序、清单和所有分卷放在同一文件夹，双击安装程序，选择一个**新的安装目录**。旧软件和旧素材先留着，不要覆盖。

安装完成后，先运行 `环境检查.cmd`。如果有“需处理”，先看具体缺什么，不要急着重新安装。检查通过后运行 `Start.cmd`，工作台会在浏览器中打开——界面在浏览器里，不代表录音必须上传到网上。

安装器目前没有数字签名。如果 Windows 拦截，先核对下载来源和文件校验结果，再决定是否继续，不要关闭全局安全防护。

## 第一次训练：先把录音整理好

准备你自己或获得明确授权的录音。尽量只有一个人说话，没有背景音乐、混响和多人重叠。先选一小批清楚的素材试流程，不要一上来就放几小时的录音。

进入“训练工作台”，按页面提示导入录音，点击“开始自动切分与转写”。完成后，**逐段播放，把文字改成录音里真正说的话**。听不清、截断或不适合的片段就排除，不要为了凑时长保留。

训练参数已经预填，第一次先用页面给出的试训起点。它不是“任何电脑都最优”的保证，也不是轮数越多越好。点击“检查素材、参数与空间”，看清提示；确认校对完成、允许占用显卡后，再点击“确认并开始真实训练”。

训练期间去“任务中心”看实际阶段。某一阶段比较慢，不一定是卡死；有报错先保存日志，不要连续点击训练。失败后的检查点可以保留，但本版不承诺自动断点续训。

训练完成会得到候选声线。到“开始配音”选择它，输入一段**训练录音里没有出现过的文字**。亲自听过没有明显漏读、错读或异常声音后，再到“我的声线”确认发布。

这里的“发布声线”是保存为本机可反复使用的声线，不是上传到互联网。以后直接选它即可，不必每次重新训练。

## 输入文案，下载音频和字幕

进入“开始配音”，新建文案并选好声线。先点“试听首句”，满意后点“生成音频与字幕”。

某一句不满意，展开“修改这一句”，检查朗读文字，再单独重做。只修改字幕显示文本不必重新配音；改了朗读内容则需要生成对应音频。最后生成或更新完整成品，让字幕时间与最终音频一致。

完成后可下载完整 WAV、字幕 SRT 或完整交付包 ZIP。SRT 是按分段音频计时的**句级字幕**，不是逐字高亮，也不是已经烧录到视频里。剪辑时间线和交付包可以交给后续流程，但本版不会自动打开剪辑软件或监控指定文件夹。

## 遇到问题先看这里

| 现象 | 先做什么 |
| --- | --- |
| 提示缺分卷或校验不同 | 对照同一版本的清单，只补缺失或损坏的文件；不要混用旧版 |
| 找不到模型、Python 或 DLL | 运行环境检查，保留结果；别先安装一堆全局依赖 |
| 显存不足 | 停止本软件当前任务，保存日志；检查是否有其他显卡任务，经确认后降低批大小再试，不随意结束别人的进程 |
| 整段读音不对 | 先核对参考音频与参考文字、语言和实际朗读文本，再用短句复测 |
| 提示核心已改变 | 核实更新来源，在“更多工具 → 环境设置”重新确认；不要手动绕过指纹检查 |
| 重开后没看到项目 | 检查是不是打开了另一个安装目录；不要删旧 data，也不要让两个版本共用同一数据库 |

反馈问题时附上版本、Windows、显卡/驱动、失败步骤和脱敏日志。不要公开上传录音、私人权重、整个 data 文件夹或带启动凭据的地址。
