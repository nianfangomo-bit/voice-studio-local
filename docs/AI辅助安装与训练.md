# 给新手的 AI 辅助安装与训练说明

## 先分清两种模型

DeepSeek V4 等大语言模型可以解释说明、分析报错，并在具备本地工具的 Agent 中协助执行操作。真正训练、生成声线的是本机 GPT-SoVITS，不是 DeepSeek；不必为了配音在电脑里再下载一套 DeepSeek 大模型。

普通聊天窗口不能仅凭一句话就控制用户电脑。实际操作取决于客户端是否提供文件、终端等工具，以及用户授予的权限。

截至 2026-11-02，DeepSeek 官方提供 Windows Harness 桌面端，说明支持本地文件读写；其官方 Computer Use 插件文档仍说明 Windows 支持在开发中。因此不能承诺 Windows 版自动点击软件、一路无人值守完成安装。当前软件也尚未验证或集成 DeepSeek 自动操作。

## 推荐给普通用户的流程

1. 从项目正式发布页取得完整离线包；不要把 Source code 当成完整安装包。当前完整 1.0.1 仍为验收草稿，尚未成为公众下载入口。
2. 安装到空间充足的新目录，优先考虑 D 盘；保留原安装和作品。
3. 运行随包环境检查。不要让 AI 为“修复”而先升级所有依赖或重新安装 Python。
4. 先由用户提供自己的或获得授权的录音，再在软件内切分、转写和逐段校对。
5. 软件预填基础训练参数；用户确认后训练。用户需要兼容的 NVIDIA 显卡和驱动；已有最小训练实测环境为 RTX 3080。
6. 用未参与训练的文字试听候选声线，满意后发布；后续直接使用，不用每次重训。
7. 若出错，让 AI 解释脱敏后的错误信息。不要直接上传整份录音、模型、文案或含密钥的日志。

离线软件本身不依赖 DeepSeek。云端 AI 辅助需要联网，可能涉及账号/API费用，提交的信息会离开本机；应作为可选帮助而非强制安装条件。

## 可复制给具备本地工具的 AI 助手

请帮助我安装和检查声线工作室。先阅读我提供的官方项目说明，并核对 Release 实际附件，不要把源码包当作完整离线包。先只读检查 Windows、显卡及驱动、剩余磁盘空间和安装目录，再向我说明结果。

不要改动我的原有模型、录音和作品；不要关闭杀毒、提权、更改系统安全设置或无条件升级依赖。只使用可信来源的文件并核对校验值。下载大文件、安装驱动或系统运行库、开始训练之前，需要我明确确认。优先用软件自带的 Python 和基础模型。

如果工具不能操作电脑，请给我逐步操作说明，不要声称已经操作完成。录音、密钥和私人文案未经我同意不能上传。协助我在软件内导入授权录音、切分转写、人工校对和训练；参数不确定时解释依据，不保证任意素材的音质。训练后使用新文字试听并保留候选版本，未经确认不要替换默认声线。

最后明确告诉我：实际通过了什么、哪里失败、已有文件是否保留，以及下一步怎么处理。
