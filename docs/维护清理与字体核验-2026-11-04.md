# 维护清理与字体核验

日期：2026-11-04。范围：`voice-studio-local` 发布源码及 `v1.0.1-offline.1` 完整离线 ZIP；不包括独立的 Math14/VoiceGuide 视频工程，不修改用户运行中的旧工作台、数据库或 GPT-SoVITS 原环境。

本轮修改仅在源码工作区，未提交、推送、重打包或覆盖公开发行包。新的源码安全修正不应误称为已修复用户下载的 1.0.1 包。

以上删除都是源代码片段，不涉及用户文件；原内容可由当前 Git 基线恢复。本轮不会为凑“清理数量”删仍有用途的代码，也不把“没有调试路由”称作“已删除调试路由”。样式减少 458 字节（UTF-8 文件大小差，含换行规范化）；字体体积没有减少。

### 特别保留的文件与函数

- `app/legacy/voice_tool/main.py`：工作台通过 `load_legacy` 动态加载其中 `split_script`、`validate_segment_wav`、`fmt_srt_time`；旧 CLI 的 `run`、`main`、`check_api` 仍构成兼容入口，不能把文件名含 legacy 当作删除依据。`check_api` 不是服务器路由。
- `app/build_portable.py`：被 `package_offline.py` 导入；`inventory` 和 `APP_FILES` 参与正式打包。
- `app/engine_entry.py`：训练进程以文件名启动，并非普通 import 调用；保留白名单执行入口。
- 测试文件及 `.github/workflows`：属于维护/构建流程，不是 HTTP 服务接口。源码发行保留测试用于回归，安装包按 `APP_FILES` 白名单排除测试。
- `app/static/app.js`：是实际服务使用的生产 bundle；不删除或逐函数添加注释，维护源文件后重建。

## 3. 字体商用核验

核验对象是实际文件与许可文本，不凭名称或“开源项目”作结论。清单含字体文件及 AFM 度量文件（后者不含字体轮廓），共 **157 项、9,387,264 字节**。逐项相对路径、SHA-256、组别与证据见 [机器可读清单](maintenance-inventory.json)。嵌套的第三方源码压缩包不算应用加载字体，未展开作为本次运行资源盘点范围。

| 字体/资源 | 实际情况 | 商用与再分发判断 | 本轮处理 |
| --- | --- | --- | --- |
| Segoe UI、Microsoft YaHei | style.css 只声明系统 font stack；仓库及包内无这些字体文件 | 系统渲染可用，不等于获得复制分发字体的免费许可证 | 保留系统调用，不复制 Windows 字体 |
| Microsoft YaHei UI | OfflineSetup.cs 使用系统字体 | 同上；安装器未嵌入字体 | 保留 |
| sans-serif | 浏览器通用字体族 | 不是一个独立字体文件；最终由系统选择 | 保留 |
| KaTeX，59 文件 | Gradio 4.44.1 的前端资源；TTF name 表明确声明 SIL OFL 1.1，WOFF 同族映射记录于清单 | 条件允许商用随包分发；保留版权/许可、保留字体名约束，不单卖字体。不能拿 KaTeX 的 MIT 代码许可证替代字体 OFL | 保留依赖，新增 `licenses/KaTeX-Fonts-OFL.txt` 供下次构建包含；已发布包未补入此文件 |
| DejaVu，14 文件 | Matplotlib 默认文字渲染资源；随包有 LICENSE_DEJAVU | Bitstream Vera / Arev 条件允许随软件分发；保留声明，不单卖字体，修改名称受限制 | 保留 |
| STIX，17 文件 | 数学字体/回退；随包有转换说明与 LICENSE_STIX | OFL 1.1 条件允许；保留原有转换说明、版权与许可，不据此授权任意改名或再修改 | 保留供应方原文件 |
| Computer Modern TTF，7 文件 | Matplotlib 数学字体；LICENSE_BAKOMA 已随包 | BaKoMa 许可允许无费用使用/分发，须满足声明条件 | 保留 |
| PDF 核心字体 AFM，14 文件 | 仅度量数据；同目录 readme.txt 给出 Adobe 许可 | 允许按条件复制分发，须保留 readme 与版权；不能外推获得 Helvetica 等完整字体文件授权 | 保留 |
| legacy AFM，46 文件 | `matplotlib/mpl-data/fonts/afm`；含 Adobe 等不同版权头 | **尚未逐项完成明确再分发授权链核验**；不能直接套用 pdfcorefonts 目录的许可，也不能只用 Matplotlib 总许可证背书 | 保留并列为待解决许可项；不能宣称全部字体商用通过 |

训练实际会通过 `GPT_SoVITS/utils.py::plot_spectrogram_to_numpy` 调用 Matplotlib。Gradio 也被引擎代码隐式导入，字体通过第三方 CSS 引用。只搜索自有 JSX 不足以证明这些资源可删；需要在下一版的独立候选包做明确裁剪与训练/渲染回归，不能删除原环境文件试运气。
