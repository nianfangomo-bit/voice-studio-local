# 1.0.3-rc.1 源码候选

这是应用源码修复版本，不是包含新 Python、torch 和模型的 50 系离线安装包。旧 Release 附件不被替换。

## 解决什么

- 环境设置可填写独立 Python 路径，新任务保存环境快照；启动器重新打开服务时读取所选环境。
- 环境切换保留旧配置；已有任务阻止切换；历史配置需要重新确认信任。
- 显卡基础矩阵与 FFT 检查；第三阶段声纹产物缺失时立即停止，并提供对应日志与错误原因。
- 供 DeepSeek/dsharness 使用的通用提示词：先检测、按证据选择候选、下载前确认、独立安装、分项验收。

## 还不能承诺什么

- 保存配置仅检查路径，不代表新环境全部依赖已验证。
- 新任务使用新配置；当前服务仍使用启动时的 Python，关闭服务再启动才更换服务解释器。刷新浏览器不等于重启服务。
- 旧失败任务重试仍保留旧环境快照；更换后应新建任务并核对实际 Python。
- 数据目录未迁移；完整升级安装器、数据库备份迁移、自动回退、在线更新未实现。
- RTX 5060 Laptop 的新环境、完整训练和配音尚未实测通过。
- 不建议小白直接覆盖旧安装；先由开发者或受约束的本机助手备份并在独立副本验收。

## 验证记录

- Python 单元测试 70 项通过，包含模拟架构不兼容、上游退出零但产物缺失、配置切换与恢复。
- 前端 6 项原有检查通过，新前端构建通过。
- 临时独立应用副本实际启动成功，认证状态、硬件检测接口、前端静态文件读取通过；未使用用户数据。不等同浏览器交互、训练或新环境验收。
- 本机 RTX 3080 的基础矩阵与 FFT 通过（使用旧独立运行环境）。不能替代 5060 测试。
- 不上传个人录音、训练权重、数据库、会话令牌或旧产物。
