# 声线工作室 v1.0.0

发布日期：2026-11-01。

白底紫蓝渐变封面用于 GitHub 项目首页。软件原有界面、绿色配色、导航和功能保持不变。发行统一版本为 1.0.0，建立 Git 标签、中文变更记录和 SHA-256 校验。

## 下载与启动

voice-studio-local-v1.0.0-source.zip 包含软件代码及已构建页面，不含 Python、引擎和模型。已有兼容 GPT-SoVITS v2Pro 环境可按 README 使用；没有运行环境的新用户不能下载该包后直接训练。1.0 完整离线包尚未发布。

解压到新的可写目录，运行 app/启动.cmd。外部环境首次启动需要系统 Python（带 tkinter），随后选择引擎运行时，在环境设置连接引擎、FFmpeg 和本包 app/legacy。旧依赖不升级。

## 从 0.2 升级

1. 等待任务完成，退出旧后台服务。仅关闭浏览器不会停止后台。
2. 备份旧软件目录，尤其 data 中的数据库、作品与素材，同时保留原引擎及模型。
3. 新版解压到新目录。1.0 未修改数据结构，可在服务停止后复制旧 data 到新版 app/data；保留原始备份。
4. 检查设置及素材绝对路径，试听旧项目后再开始新任务。回退时使用旧程序与升级前数据。

## 验证与限制

本次测试结果见 1.0验收记录.md。训练与配音逻辑沿用既有版本，本次未新跑 GPU 训练。历史 RTX 3080 10GB 训练、生成及 0.2 离线安装/转写结果不等同于 1.0 干净系统验收。

干净 Windows、RTX 2060 6GB 和独立离线训练尚未全流程实测。字级字幕、MP3、固定目录自动发送剪辑、读音词典尚未交付。SRT 为句级时间轴，不自动烧录到视频。

旧版离线分卷仍属旧版本，不与 1.0 混装；不以版本号替代功能验收。
