## 使用入口

新装：在独立目录解压应用，双击 `app/Start.cmd`，没有随包解释器时选择可信整合环境的 `runtime/python.exe`。此包不提供 Python 或基础模型，不是完整离线包。应用仍需完整的引擎及旧配音核心，不能只下载源码就训练。

升级已有数据：先停止新旧服务和训练进程；新版应用还没有 data 目录时，双击新版 `app/MigrateData.cmd`。选择旧软件 data 目录，再选择新版 app 目录。迁移成功后启动新版，逐项核对素材、声线和作品。

目标已有 data 时拒绝合并。不要删除唯一数据来绕过；应换一个干净的新应用目录。外部导入的权重、引擎及原目录外文件不会搬迁；旧目录不能直接删除。迁移报告含本机路径，不要公开上传。中断后的 `.migrating-*` 是保留的暂存成果，不会自动当成可用数据库。

遇错：任务中心查看阶段日志；环境设置下载脱敏摘要。分享原始日志前人工检查个人路径、文案等信息。

回退：关闭新服务和训练进程，使用保留的旧应用入口。新产生的数据不自动倒灌旧库，保留新版目录；不得以删除新版目录作为通用回退方法。
