## 本轮发现并修复

1. 上传超限、空文件、断流可能遗留 `.partial`。只删除当前请求创建的未完成文件，不清理原始素材或不明旧文件。
2. 启动器可能在旧服务暂时不响应时抢先把运行任务标为中断。移除启动器的数据库恢复，交由独占服务执行。
3. 分卷清单未绑定同一版本及顺序、Windows 设备名路径未拦截、解压体积允许误差。现在严格检查。
4. 发布说明写死四个分卷，且缺少整包上传前校验。改成实际数量并在访问凭据和网络写入前核验文件。

## 授权调查证据与限制

- https://huggingface.co/TencentGameMate/chinese-hubert-base/blob/main/README.md ：读取到 `license: mit`。还需随发行材料记录具体上游修订及对应资产。
- https://github.com/koshort/pyeunjeon/blob/master/LICENSE ：读取到 GPL v3 或以后版本。不是“不能使用”，而是不能以项目 MIT 许可替代其义务；中文精简构建拟排除未用的此组件。
- `LangSegment 0.3.5` 的本地 METADATA 标注 BSD；本次精确 PyPI 版本和原 GitHub 入口返回 404。404 不证明许可失效，也不证明再分发材料齐全。代码检查发现当前引擎另用内置 LangSegmenter，因此拟排除遗留包。
- 以上新排除项只在生成新的发行归档时生效，原环境及旧候选包未修改。核心隔离导入检查通过，但不等同新完整包训练通过。
