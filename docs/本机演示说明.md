# 声线工作室：本机演示

版本：1.0.3-rc.2。本说明针对已有配套环境的本机演示，不是面向所有电脑的安装承诺。

## 演示什么

用有授权的录音微调一个声线，之后不再重复训练：输入新文案，生成音频，改一句只重做一句，再导出 WAV 和句级 SRT。

## 建议顺序（3～5 分钟）

1. 双击演示副本的 `app/Start.cmd`，等待浏览器出现工作台。不要把 Remotion 的 VoiceGuide 页面当成软件入口。
2. 打开“训练工作台”，展示已有素材、校对文字和训练参数。说明这是此前真实执行的训练，不在演示现场等待完整训练；21.8 秒素材属于链路验证样本。
3. 打开“我的声线”，展示试听确认后的可用版本。这里的“发布”只表示本机可用，不会上传声线。
4. 回“开始配音”，展开“输入新文案”，选择声线，输入三句话，保存并分段。先试听首句也可以，全文生成后会出现完整音频和下载入口。
5. 展开第二句的“修改这一句”，改朗读文本；普通文案可点“将朗读文字填入字幕”，公式则分开编辑。保存后只重做这一句，再下载新版本。
6. 下载 WAV、SRT；在作品库展示旧版仍保留。字幕是独立句级文件，不是视频烧录字幕或逐字对齐。

若现场等待模型加载，可以先播放已经生成的成品，并明确说明该成品是之前生成的；不要把预制结果当成刚刚生成。

- 本机 3080 已完成真实训练、配音、重开进程复用、单句重做和复制迁移后复用；浏览器中完成第二版成品，WAV/SRT 下载已核对。
- 本机演示入口及截图保存在私有验收目录，分别为 `本机演示入口.md`、`demo-ui-20261115.png`；不作为公开发行附件。
- 使用现有 GPT-SoVITS v2Pro 环境，应用代码和测试数据独立保存。
- 用户已试听确认样本可用于本次演示。不是音质评级，也不是任意录音质量承诺。
- 50 系本候选复验、完整断网流程、完整离线包重打、首次环境选择弹窗、迁移向导全部点击路径仍不在本次已验收结论中。
- 不重新设计 UI，不新增自动更新、英文日文或通用视频剪辑能力。

## 遇到问题

任务中心查看失败阶段；环境设置可下载脱敏摘要。不要公开原始日志、录音、数据库或私有权重。先保留结果，不原地升级 Python/torch，不删除旧版目录。

演示达到停止线后可以转新项目；兼容性和发行工作保留为单独待办。
