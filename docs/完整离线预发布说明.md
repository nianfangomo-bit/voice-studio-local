# 声线工作室 1.0.1 完整离线版（预发布）

这次提供的是包含运行环境和基础模型的完整包，不只是源码。

## 怎么下载

下载本页的 `VoiceStudio-Offline-Setup.exe`、`offline-package.json` 和全部 **25 个 .part 分卷**（001～025），放在同一文件夹，双击安装程序。

- 下载约 **6.02 GiB**，解压约 **9.30 GiB**；安装建议预留至少 30 GB，训练另预留至少 12 GB。
- `DownloadOffline.ps1` 是可选的批量下载与校验脚本；不会自动执行安装。也可以完全手动下载，不必运行脚本。
- 不要将旧草稿的分卷混入，也不要下载 GitHub 自动生成的 Source code 代替完整包。
- 安装后先运行 `环境检查.cmd`，再运行 `Start.cmd`。不需要手动安装 Python、CUDA Toolkit 或另找基础模型。

## 包含什么

中文工作台、Python 3.9.13、GPT-SoVITS v2Pro 引擎、训练与配音基础权重、中文转写模型、音频工具，以及对应版本记录和第三方许可材料。

使用流程：创建声线 → 导入本人或获授权录音 → 自动切分转写 → 逐段校对 → 确认参数训练 → 候选声线试听发布 → 输入新文案生成 WAV 和句级 SRT。训练好的声线可以继续复用。

软件保持原来的界面和配色。本次不包含个人录音、个人微调模型或作品数据。

## 已知限制

- Windows 10 更新版 / Windows 11 64 位，训练和当前配音引擎需要兼容的 NVIDIA 显卡驱动；软件不会替用户安装显卡驱动。
- 尚未在另一台没有开发环境的 Windows 电脑完成全流程测试，因此先按预发布提供，不承诺所有机器兼容。
- 短素材最小训练只验证链路，不代表声线质量；机器转写复核不能代替人工试听。
- 字幕是句级，不是字级精细对齐。普通用户仍需校对转写和试听成果。
- 安装器尚未商业签名；依赖按兼容性固定，不代表最新安全版本。只加载可信模型，不把服务开放到公网。
- 升级使用新目录，备份旧 `data`，不要覆盖原声线和作品。没有自动跨版本迁移承诺。
