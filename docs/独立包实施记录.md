# 独立运行包实施记录

日期：2026-10-31。目标：用户拿到完整包，能够整理自己的录音、训练并重复使用声线。

## 本次实际完成

- 训练页直接选择多个 WAV / MP3 / M4A / FLAC / OGG 文件，不再要求普通用户先填写 `.list` 路径。
- 导入前确认授权；原文件另存，服务器生成文件名，同名上传不覆盖原文件。
- 真实 FFmpeg 解码、静音切分、CPU 本地 FunASR 转写；不调用官方入口中隐含的在线下载函数，整理进程禁止联网。
- 测量音量、近满幅采样比例并给提示；不是音质评分，不能可靠检测所有噪声、口音或重叠说话。
- 长连续语音拆成不超过 10 秒片段，强制边界标记待检查；短于 1 秒或近乎全静音的片段默认排除，仍保留可见。
- 整理任务排队、真实阶段、取消、失败信息、重启恢复已完成片段。重新整理留存旧版 JSON 与音频，不覆盖人工校对记录。
- 每段可播放、改文字、确认或排除；未校对和空标注不能进入训练。至少有一段 3～10 秒可用于参考。
- 新素材默认填入 GPT 5 轮、SoVITS 8 轮、批大小 1；这些是保守起点，不是最优参数承诺。
- 启动脚本优先使用包内 `engine/runtime/python.exe`，首次自动连接随包引擎、旧核心和 FFmpeg；系统 Python 不再是完整包的必要依赖。
- 独立本机候选目录已复制约 9.51 GiB 引擎及基础模型，不含用户训练权重。保留原项目环境不动。

## 仍未通过的发布门槛

- 独立包的完整训练、候选声线生成与新文本配音验收（需要用户确认占用显卡后执行）。既有开发环境训练通过不替代此项。
- 没有在全新 Windows 或 RTX 2060 6GB 实机测试。搬到另一目录验证不等于干净系统验收。
- 第三方 Python / CUDA / FFmpeg / ASR 等组件的再分发材料尚未逐项核对，候选目录禁止直接公开上传。
- 当前是可解压运行的目录候选，不是带签名的 EXE 安装程序；尚无安装卸载向导。
- 自动切分不保证不切断词语；尚无可视波形拖动边界编辑。可以试听排除，或用外部编辑后再导入。
- 旧校对记录保留在数据目录的 revision JSON 中，尚无界面一键回滚。

## 本机试用

打开 `../voice-studio-offline-candidate/启动.cmd`。本机验收页面为 `http://127.0.0.1:8792/`，首次访问必须通过启动器建立会话。

训练工作台 → 选择录音并说明授权 → 保存录音 → 开始自动切分与转写 → 逐段试听校对 → 检查训练计划 → 确认训练 → 用未见过的新文字试听候选声线 → 满意后发布。

候选目录运行后含本机测试数据，不得将整个目录作为公开包。正式发行应从干净白名单重建，并进行许可及隐私复核。
