# 1.0.2-rc.1 候选版收尾

日期：2026-11-05。仅完成字体分发策略和本地源码版本整理，不是新的完整离线安装包发布。

## 字体结论与实现

旧包中 46 个 `matplotlib/mpl-data/fonts/afm/*.afm` 的逐文件授权依据仍不完整。本次不作“全部免费商用”结论，改为在新候选构建中排除这批旧 PostScript 度量文件。源环境、旧 ZIP、用户数据均不删除。

`build_portable.inventory` 和完整离线构建共用精确路径规则，仅排除目标目录的 AFM 文件。保留字体许可、TTF 和 `pdfcorefonts` 目录。新离线包的 `build-choices.json` 将记录每项排除文件的相对路径、大小与 SHA-256。已核对当前输入为 46 项，共 758,646 字节；这不是压缩包实际节省值。

这意味着候选环境不保证外部程序主动开启 `ps.useafm=True` 时的旧 PS 字体兼容；软件的配音、字幕及训练频谱图不使用该功能。[Matplotlib 官方字体说明](https://matplotlib.org/3.5.3/users/explain/fonts.html)区分了 AFM/Core Fonts 和常用字体渲染。这里的排除是分发风险控制，不是对旧文件作侵权判断。

其他字体沿用上一份维护报告的条件许可结论；KaTeX 字体 OFL 补充通知已纳入许可证目录。不能把 JavaScript 库 MIT 许可当作字体许可。

## 本轮验证

- 对已有 Matplotlib 3.6.2 的资源建立独立副本，实际不复制这 46 项，使用全新字体缓存。
- 直接提取现有引擎 `plot_spectrogram_to_numpy` 函数 AST 执行，得到 200×1000×3 非空频谱图；并输出含文本与公式的 PNG、PDF、SVG。
- 这是实际绘图的隔离测试，不是完整引擎导入、GPU 训练或最终安装包测试。记录见 `font-policy-check.json`。
- 首两次绘图通过但临时目录清理遭遇 Windows 字体句柄占用；测试工具已改为子进程绘图、退出后父进程清理，第三次完整退出码为 0。先前记录和少量测试副本留在工作区 work 中，不进入发行文件。
- 新增精确排除范围与核心指纹变更拒绝执行的回归测试。
- 本轮 55 项 Python 测试与 6 项前端检查通过；自有 Python 共 197 个函数均有相邻中文注释。
- `maintenance-inventory.json` 的函数部分对应当前源码，字体部分仍是原 1.0.1 完整包的 157 项历史证据；不能误读为新包已验收。候选排除清单另见 `font-policy-check.json`。

## 升级策略

版本统一为 `1.0.2-rc.1`，不覆盖 `1.0.1-offline.1` 的源码或安装资产。尚无本版完整离线包或公开发布标签。

旧核心新增注释会改变文件哈希。已有数据如果指向更换后的核心，会提示“旧配音核心已改变，请在环境设置中重新确认并保存”。用户核实路径和来源后自行确认；软件不静默修改信任记录。若继续指向原核心则不会因新源码自动迁移。

明天升级实测前：停止旧应用，备份完整用户数据目录；新版本装到独立目录。不要让两个版本同时打开同一数据库；不要只备份数据库而遗漏引用的录音、权重和作品。本轮没有自动迁移用户数据。
