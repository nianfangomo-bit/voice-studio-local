# 声线工作室 1.0.2-rc.1 · 完整离线候选版

供另一台 Windows 电脑安装和训练验收的预发布版本，不是已完成异机验证的稳定版。

## 下载什么

[本版本发布页](https://github.com/nianfangomo-bit/voice-studio-local/releases/tag/v1.0.2-rc.1)

下载同一发布页的 `VoiceStudio-Offline-Setup.exe`、`offline-package.json`、全部 `.part` 分卷、`SHA256SUMS.txt`。阅读 `INSTALL.txt` 和 `ACCEPTANCE.json`。也可先检查 `DownloadOffline.ps1`，用它下载并校验本版本。

所有文件放在同一目录，然后启动安装器。GitHub 自动生成的 Source code 不是完整安装包。不要把 1.0.1 和 1.0.2 分卷混在一起。

完整包包含 Python、GPT-SoVITS v2Pro、训练和配音基础模型、中文转写模型、FFmpeg、中文工作台及许可材料。不需自己安装全局 Python 或拼装模型环境；仍需满足 Windows 64 位系统和兼容 NVIDIA 驱动等运行条件。建议安装阶段至少预留 30 GB，训练另预留空间。

## 本版变化

- 保持原界面配色，清理无用样式和导入，补充中文维护注释。
- 限制片段试听和作品导出的文件访问范围。
- 补充 KaTeX 字体 OFL 通知，新包排除 46 个许可链待确认的旧 PS AFM 度量文件，不删除用户原引擎。
- 保留环境信任校验；更换核心代码后由用户核实来源并重新确认。

## 验收边界

55 项 Python 测试、6 项前端检查及独立字体资源绘图测试通过。最终分卷已用安装器实装到同机新目录，38,233 文件深度校验、依赖导入及工作台认证启动通过；不是另一台电脑的验证。最终包为 6,467,119,509 字节，共 25 个分卷，解压约 9.30 GiB。详情见随发布附件的 `ACCEPTANCE.json`。

**本候选包尚未完成：真实训练与新文本配音全链路、关闭网络后的核心流程、另一台 Windows 电脑测试、升级及取消恢复的端到端验收。** 原 1.0.1 的训练成功记录不能替代这些检查。不保证所有显卡、系统或录音都能产生理想结果。安装器未签名，也未做独立安全审计。

## 开始使用与升级

安装到新的独立目录，运行 `环境检查.cmd`，再运行 `Start.cmd`。准备有使用授权的录音，依次创建声线、导入、切分转写、校对、确认参数训练、试听候选、发布声线；以后选择该声线输入文案生成 WAV 和句级 SRT。

升级前停掉旧程序，备份完整数据目录和引用的素材。不要覆盖旧版或同时用两个版本打开同一数据库。旧版下载仍保留。遇系统拦截先检查来源，不要全局关闭防护。
