# 给 DeepSeek/dsharness：声线工作室 1.0.3 下载、安装与验收

请先说明你是否真有这台 Windows 电脑的终端、文件和网络操作权限。没有权限时只给人工步骤，不要声称已经下载或安装。目标是让普通用户从同一个 GitHub Release 获得完整离线包，装完后能用自己的授权录音切分、校对、训练和配音；不是下载 Source code ZIP 后自己拼 Python。

项目仓库：`https://github.com/nianfangomo-bit/voice-studio-local`。先读实际 Release 资产和对应 `ACCEPTANCE.json`，不要仅凭 README 或本提示词认定新版已经发布。若找不到版本一致的完整包，直接说明“该配置的可下载包尚未发布”，停止，不拼旧版分卷或自行改源码。

1. 只读检测 Windows x64、显卡型号与计算架构、驱动、显存和可用磁盘空间；检查已有声线工作室与数据位置。不要读取或发送会话令牌、录音、模型权重和文案。不要只用“30 系／50 系”名称推断兼容；资料不全就标未知。
2. 根据发布页中**实际存在**的包、硬件适用说明和验收记录选择候选。已知旧版 1.0.2-rc.1 的 CUDA 11.8 环境在 RTX 5060 Laptop 出现过 FFT/NVRTC 错误，不能拿旧包在该机反复训练。3080 本机测试不等于其他显卡保证可用。没有明确适配该机的完整包，就先报告开发者，不把上游引擎归档说成本软件安装包。
3. 下载前向用户说明：准确版本与来源、总下载量、安装位置、峰值空间、是否会联网、如何保留旧版。得到同意后只下载同一 Release 的 `VoiceStudio-Offline-Setup.exe`、`offline-package.json`、`SHA256SUMS.txt`、`INSTALL.txt`、`ACCEPTANCE.json` 和全部 `.part`。可以用同版 `DownloadOffline.ps1` 辅助，但先检查脚本；不要执行来自评论区的陌生命令。
4. 每个文件按清单核对大小和 SHA-256，合并 ZIP 摘要也必须一致。缺卷、校验不符、版本混用时停止；不要关掉证书验证或安全防护。只装到新的独立目录，保留原版 `data`、录音和模型。不要自动升级显卡驱动或单独 `pip install --upgrade`。
5. 安装后运行随包 `环境检查.cmd`，确认 Python、引擎、基础模型、FFmpeg 和 CUDA 基础运算来自**新安装目录**。检查通过还不等于训练成功。用授权素材实际走：导入 → 切分转写 → 人工校对 → 训练 → 未见文本配音 → 发布声线 → 重启复用 → 单句重做 → WAV/SRT 导出。长时间训练先征得用户同意。
6. 记录每一步“真实通过／模拟测试／未测试／失败”，记下软件版本、运行环境和错误阶段。失败时保留日志、素材、检查点与旧版，不自动清空数据；分享日志前检查私人信息。不要把个人录音、数据库、训练权重或成品上传 GitHub。
