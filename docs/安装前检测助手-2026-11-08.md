# 安装前检测与候选推荐交付记录

本轮在不下载大包、不改驱动和旧环境的约束下实现检测推荐入口。

## 实现

- `app/HardwareAdvisor.cs`：独立 .NET Framework Windows x64 助手，不依赖 Python；界面及 `--json` 共用检测规则。
- `app/hardware_advisor.py`：仅调用固定随包助手，限制 20 秒，不接受任意执行路径。
- `GET /api/hardware-advice`：受原有会话、Host、Origin 防护。
- `ui/HardwareAdvice.jsx`：环境设置页展示硬件、候选包限制和官方入口，可导出白名单报告。
- 只在用户确认后打开固定官方 URL，不自动下载安装；支持已下载上游 50 系归档哈希校验，但不解压、执行或切换。
- 模块进入便携包/源码包白名单；前端已构建，未覆盖旧安装的文件。

## 证据

- 65 项 Python 测试通过（含新增 4 项助手规则、超时、未知格式、鉴权检查）。
- 前端原有 6 项检查通过；新 JSX 构建通过，未声称浏览器交互已验收。
- 真实硬件检测：RTX 3080 / 610.74 / 8.6 / 10240 MiB；系统 Windows 11 25H2 build 26200.7462。
- 5060 规则测试是模拟，不能替代朋友电脑验收。
- 编译器 Framework64 v4.0.30319 csc，目标 winexe/x64；通过重定向标准输出供服务读取，不显示终端。
