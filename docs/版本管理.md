# 版本管理

版本格式为主版本.次版本.修订版本。1.0.0 起，问题修复发布 1.0.1；新增兼容功能发布 1.1.0；不兼容数据或接口变更发布 2.0.0，附迁移说明。试验版本使用 -alpha.N 或 -rc.N，并标记为预发布。

每次发布同步根目录 VERSION 与 app/package.json。UI 和离线打包从 package.json 读取版本；源码打包脚本校验两处一致。更新 CHANGELOG 与验证记录，通过必要测试，再创建不可移动的 vX.Y.Z 标签，指向实际发行提交。

在同名 GitHub Release 发布白名单资产、清单和 SHA-256。不得覆盖同版本文件或移动已发布标签；任何修复发新版本。保留旧版本，不强推覆盖历史。软件包与完整离线模型包必须明确区分。

升级前结束任务并关闭后台，备份旧程序及 data；新版解压到新目录。原始素材、模型、data、凭据和日志不进入公开仓库。回退使用旧版本目录和升级前的数据备份。本软件尚无自动更新器。
