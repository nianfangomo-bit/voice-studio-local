# 视频文案（当前预发布版，约 90～120 秒）

## 标题

训练一次，反复配音：我的本地声线工作台实测

## 旁白与画面

【开场：真实界面，不用动画假装操作成功】

如果你想用自己的声音给视频配音，每次都重新训练，其实没有必要。我把 GPT-SoVITS 的训练和配音流程整理成了一个中文工作台：先保存声线，之后输入新的文案，就能继续生成配音。

【展示版本与限制】

先说清楚，现在发布的是开发预览版，需要已有兼容的 GPT-SoVITS 环境，还不是下载一个压缩包就能直接训练的完整离线版。它使用 Codex 辅助开发，但不是 OpenAI 或 GPT-SoVITS 官方产品。

【展示本人录音及校对，隐藏私人文件路径】

创建声线前，要确认录音是自己的，或者已经取得授权。现在可以直接选择录音，在工作台里切成片段、自动转成文字。每段都要试听，文字不对就修改，有噪声或读不清的片段可以排除。

【展示真实训练计划与日志，可快放并标注】

确认材料后，检查环境和训练参数，再开始微调。这里显示的是实际阶段，不是假的进度条。显卡、片段长度和批量都会影响能不能跑，不能只看一个显卡型号就保证所有配置可用。

【展示候选声线用新文本生成】

训练结束还不算验收完成。换一段没参与训练的文字，检查读音、漏字和声音相似度。满意后保存发布，下次直接选这条声线，不用再训练。

【输入文案、试听首句、生成全文】

配音时先试听一句，没问题再生成全文。某句话需要改，就修改这一句，再生成对应片段，不必整篇重来。

【展示 WAV、SRT 和交付包，录制前复测时间更新】

完成后可以导出音频和句级字幕，放进剪辑软件。字幕文件和把字幕压进画面是两件事，不要混淆。

【结尾：版本页及真实限制】

下载方式、兼容环境和已知限制都写在项目说明里。完整离线包正在验收，固定文件夹交付还在完善中。你可以先看真实流程，再决定这版是否适合自己的电脑和素材。

## 录制注意

- 不展示作者私人路径、个人训练资料、浏览器凭据或他人声音。
- 训练录像快放时标注“加速播放”，不捏造耗时与进度。
- 不宣称“2060 全流程实测通过”“任何电脑都能训练”“永久免费商用所有声音”。
- 不把“官方可少样本微调”改写为“任何一分钟素材必定高质量”。
- 完整离线版未交付前，不使用“下载即用／一键训练无需配置”的封面。

## 完整离线版验收通过后才可替换的开场（现在勿发布）

下载完整离线包，解压后打开启动器，先检查电脑和模型环境。通过检查后，导入授权录音，按向导切分、校对、微调并试听。声线保存以后，输入新文案就能继续生成配音和字幕。具体支持的显卡、系统和已知限制，请以这个版本的发布说明为准。
