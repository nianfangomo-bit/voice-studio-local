# “用户下载后可以训练”交付标准

这是本项目制定的验收标准，不是 OpenAI 的产品认证，也不是 GPT-SoVITS 对本软件的背书。

## 官方指导如何落实

Codex 官方最佳实践要求明确完成条件、运行相关测试、确认最终行为并审查变更。我们将其落实为下面的可重复验收，而非用“由 Codex 开发”代替质量证明。

来源：https://developers.openai.com/codex/learn/best-practices

## 完整离线版必须具备

1. 干净 Windows 10/11 x64 机器，没有系统 Python、Node、FFmpeg，也能通过自带启动器打开；不要求用户改代码或命令行安装依赖。
2. 包含经过许可审查的固定版本运行时、训练和推理引擎、必要基础模型、转写模型、音频处理工具及中文说明。驱动依赖独立说明，缺失时给出官方获取路径。
3. 解压前说明所需磁盘空间，首次启动检测显卡、可用显存、模型完整性及目录写入权限；任何安装或下载需告知内容和体积，不静默升级用户环境。
4. 在中文路径、空格路径、无管理员权限场景中测试。服务仅回环监听，凭据和来源校验有效，不开放任意命令执行或文件读取。
5. 用户授权录音后，可直接导入常见录音；保留原件，切分、转写后逐段试听、纠正文字、排除片段。不能让普通用户手写 `.list` 才能开始。
6. 检测静音、削波、音量异常；无法自动判断的音质和转写问题明确要求人工确认，不编造评分。
7. 根据硬件和片段情况提供可解释的起始参数；低显存时小批量，训练和推理不同时占用同一卡。参数只是起点，不承诺最好音色。
8. 真正执行数据准备、GPT 和 SoVITS 微调；展示阶段或实际日志，不假装百分比。失败保存日志及产物，仅支持引擎真实提供的恢复能力。
9. 训练候选版本用未参与训练的文案试听，用户确认发布后长期保存。重启后能重新加载该权重、参考音频及原文继续配音。
10. 输入中文文案后生成可播放 WAV 与对应句级 SRT；单句重做不改变其余音频，后续时间同步更新。保留生成参数、稳定片段 ID 和历史成品。
11. 输出交付文件夹可由用户选择；版本目录完整写入、校验后才变为可导入状态，失败不留冒充完成的文件，不覆盖旧成果。
12. 分别测试缺模型、显存不足、无权限、磁盘空间不足、损坏素材、取消、进程异常和重启；错误告诉用户下一步做什么以及成果是否保留。

## 验收分层

| 层级 | 必须提供的证据 | 当前情况 |
|---|---|---|
| 逻辑测试 | 测试命令、结果、版本 | 原工作区已通过 17 项后端测试和 6 项声线选择检查；发行副本需复测 |
| 开发机真实功能 | 真实训练产物、重新加载、生成、字幕与局部重做 | 有开发机记录，私人素材不随包公开 |
| 干净系统 | 无系统 Python 的安装与全流程录像 | 未完成 |
| 低显存机器 | 2060 6GB 等实机数据与推荐参数 | 未完成 |
| 授权和隐私 | 模型与工具逐项许可、无私人文件检查 | 当前仅发布应用代码，不打包引擎或模型 |
| 普通用户教学 | 按教程独立完成，记录卡点 | 未完成 |

只有这些缺口补齐并有证据，才能在发布页和视频里说“下载完整包后，按向导即可训练”。当前只能说“已有兼容环境的用户可试用半自动工作流”。

## 版本策略

- `v0.1.x-alpha.N`：外部引擎开发预览，明确限制，不当正式安装包。
- `v0.2.x-beta.N`：计划用于整合启动、素材向导、文件夹交付的封闭测试；尚未发布。
- `v1.0.0`：通过完整交付验收后才发布；不预定未验证功能的完成日期。
- 每个 Release 附变更记录、已知限制、SHA-256、测试平台、模型/引擎版本与许可证清单。不要用“latest”替代实际兼容版本。
