# 下载与使用教程

## 先选对下载方式

### A. 本项目 GitHub Release（预发布应用包）

计划在本项目 Releases 提供 `voice-studio-local-v0.2.0-alpha.1-source.zip` 与 SHA-256（是否已上传以真实发布链接为准）。它是应用源码和预构建页面，不是完整离线环境。没有配套环境的普通用户不要期待双击后直接训练。

GitHub 自动生成的 `Source code (zip)`、`Source code (tar.gz)` 是仓库源码快照，也不包含基础模型。

### B. GPT-SoVITS 官方 Windows 整合包

从官方中文 README 的“安装 → Windows”进入整合包或国内下载入口。不要从陌生网盘下载来历不明的模型。

官方入口：https://github.com/RVC-Boss/GPT-SoVITS/blob/main/docs/cn/README.md#安装

本工作台的开发环境基于 `GPT-SoVITS-v2pro-20250604`。官方当前最新包可能已升级；下载时核对版本，不保证最新版本与本工作台兼容。官方整合包可双击 `go-webui.bat` 使用其自身界面，但不等于本项目自动包含其全部功能。

国内入口以官方 README 链接为准，不在本说明复制可能失效的临时提取码。

### C. 手动安装／基础模型下载（开发者）

从官方仓库按所选版本的说明安装环境；基础模型官方地址：https://huggingface.co/lj1995/GPT-SoVITS 。明确模型家族及路径，不能混用未经验证的权重组合。不要在已正常工作的旧环境上直接升级。

### D. 完整离线版（本机候选已构建，未公开提供）

目标是应用、运行时、引擎和必要模型一起校验后交付。只有通过干净系统验收后才开放下载。若资产超过 GitHub Release 单文件 2 GiB 限制，采用标明顺序和校验值的分卷，或提供有版本和哈希的独立模型包；当前不提供虚构下载链接。

GitHub 限制来源：https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases

## 当前预发布版启动

1. 备好可信且兼容的 GPT-SoVITS v2Pro Windows 整合包、必要预训练模型和 FFmpeg。
2. 本版启动器需要系统 Python 与 tkinter；若没有，先停止，不要把启动失败当成显卡不足。完整包将解决这项依赖。
3. 解压本应用包，进入 `app`，双击 `启动.cmd`，选择整合包目录。
4. 在“更多工具 → 环境设置”中选择引擎；“旧配音工作流”填写本包的 `app/legacy` 目录，FFmpeg 选择实际 `ffmpeg.exe`。
5. 点击检查环境；不通过时先解决缺失项。软件不会自动下载模型或修改旧环境。

## 当前训练操作（半自动）

1. 仅使用本人或有明确授权的录音，保持单一说话人、清晰、不过曝，尽量无伴奏和混响。
2. 打开训练工作台，填写声线名称与授权来源，选择原始录音并保存。支持 WAV、MP3、M4A、FLAC、OGG，单条不超过 30 分钟和 512 MB。
3. 点击“开始自动切分与转写”。使用本地 CPU 和已安装的中文模型，不自动下载；缺失时明确提示。已有切分文件也可从折叠入口导入 UTF-8 `.list`，格式为 `音频路径|说话人|ZH|对应文字`。
4. 逐条播放，核对文字后保存；不合适的片段排除，强制切分边界尤其要检查。至少保留两段，并含一段 3～10 秒可作参考的录音。新原始录音素材预填 GPT 5 轮、SoVITS 8 轮、批大小 1；旧 `.list` 导入仍沿用批大小 2。均不是最优参数承诺，可在折叠参数区调整。
5. 查看训练计划和资源提示，明确确认后开始。等待各阶段真实完成，训练时不要同时运行其他高显存程序。
6. 完成后先得到候选声线。输入训练材料里没有的新文本试听，检查漏字、重复、读音和像不像本人，再确认发布。
7. 之后新建项目选择已发布声线，输入新文本即可生成，无需重复训练。声线记录连同 `data` 保存，升级和迁移前务必备份。

## 配音与字幕

先试听首句，再生成全文。修改一句时只重做对应句，完成后再下载新的 WAV 与 SRT。字幕是句级时长，不是精细字级对齐。WAV/SRT 英文缩写、多音字或公式需要人工校正“朗读文本”；字幕显示文字可以保留原样。

当前通过“更多导出”下载 ZIP 后解压到所需剪辑目录；固定文件夹一键发送尚未实现。SRT 导出不等于字幕烧录，也不等于已经验证所有剪辑软件兼容。

## 常见问题

- 没有音频：先看任务状态和日志，确认模型、参考音频及参考原文匹配；不是所有问题都靠多训练解决。
- 显存不足：减少批量、检查长片段、关闭其他显卡任务。不要承诺降低参数一定成功。
- 声音变了：确认选中的声线和页面上的参考文字。候选和导入版需先试听。
- 关页面会丢吗：关闭浏览器不停止服务任务；机器或服务中断后需查看恢复状态，不能承诺训练一定断点续训。
- 下载失败：原成品保留在作品库，不覆盖历史；检查磁盘与目录权限。
