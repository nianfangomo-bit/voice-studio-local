# 环境选择与接续记录

## 最新范围

用户决定由 DeepSeek/dsharness 在下载前检测电脑，再依据官方来源协助下载配置。不再扩展安装助手、自动下载或自动更新器。已有硬件检测代码保留为折叠可选工具。

## 本次源码改动

- `Studio.configure` 支持显式 runtime；默认仍是 engine/runtime/python.exe。只允许 python.exe，并要求 trusted 确认。
- 新任务原有 request.settings 快照继续沿用，训练/配音/转写工作进程都使用此快照的 runtime。旧任务重试仍使用旧快照，不应宣称自动迁移。
- 环境切换时保存之前配置到 SQLite environment_history；界面展示最近十项，选中后需重新确认信任并保存才生效。
- 有排队、运行、取消中任务时禁止切换。
- launcher 只读 SQLite 获取已选 runtime，不再无条件覆盖 bootstrap。已选 runtime 丢失时明确停止，不静默用旧环境。
- server 不再因已选 runtime 丢失自动覆盖设置。
- 现有服务进程在保存后仍使用原 Python；新的工作任务使用新配置，重新启动服务后服务自身才使用所选 Python。界面明确说明。
- 录音、模型、作品和数据目录保持原位置，没有自动搬迁。

## 测试与限制

- Python 70 项测试通过，新增覆盖启动选择优先级、配置历史恢复、已选环境缺失、忙碌禁止切换与信任确认。
- 前端构建通过，未宣称此次原生窗口或浏览器全流程验收。
- 这是路径配置和启动一致性修复，不是“验证通过后原子切换”的完整环境管理器。保存仅标 paths_only。
- 新环境依赖检查、短段配音与 5060 完整训练仍待实际环境准备后验收；无大下载和长训练。
