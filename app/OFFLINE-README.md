# 声线工作室完整离线包

版本：0.2.0-alpha.2，Windows 64 位，GPT-SoVITS v2Pro。

本包包含应用、Python 运行环境、GPT-SoVITS 引擎、训练/配音基础模型、本地中文转写模型和 FFmpeg。使用自己的录音切分、转写、校对、训练；保存声线后，可以反复输入新文案生成 WAV 和句级 SRT。处理不需要云端 API。

## 第一次使用

1. 将整个 ZIP 解压到可写、路径较短的目录，例如 `C:\VoiceStudio`。不要在压缩包内运行，不要只拖出启动文件。解压后约 10 GB，训练另预留至少 12 GB。
2. 双击 `环境检查.cmd`，确认随包文件、运行库和显卡可用。软件不要求另装 Python、CUDA Toolkit 或用命令安装依赖；电脑仍需兼容的 NVIDIA 显卡驱动。当前训练和配音需要可用 CUDA，录音整理使用 CPU。
3. 双击 `启动.cmd` 或 `Start.cmd`，浏览器会打开本机工作台，环境路径首次自动填写。全部数据保存在本软件 `data` 文件夹。
4. 打开“更多工具 → 训练工作台”，填写声线名称和授权来源，选择本人或获授权录音，点击“保存录音”。
5. 点击“开始自动切分与转写”。最多 30 个录音，单条不超过 30 分钟、512 MB。支持 WAV、MP3、M4A、FLAC 和 OGG。
6. 逐段播放并校对文字；确认准确后保存，不合适的片段可排除。强制切分边界需要特别检查。至少保留两段，其中一段 3～10 秒作为参考录音。
7. 基础参数已填写，先检查训练计划，再确认训练。默认 GPT 5 轮、SoVITS 8 轮、批大小 1。若显存不足，先查看日志和环境提示，不要重复创建同一个任务。
8. 训练完成后得到候选声线，用没有参与训练的新文字生成并试听。满意后发布；以后直接选择此声线配音，不需要重新训练。
9. 在配音工作台输入文本，先试听首句，再生成全文。成品可下载 WAV、SRT 和交付 ZIP。

## 保存与升级

原录音、整理片段、校对记录、任务日志、训练模型和配音作品在 `data` 中。退出浏览器不等于停止后台任务。升级前备份整个 `data`，不同版本先解压到不同目录，避免覆盖。

## 这版的验证情况

已在开发机验证自带 Python、模型、CPU 切分转写、工作台接口和页面。既有 v2Pro 环境已完成过真实训练与配音。完整离线包的新一轮训练和全新 Windows 安装仍未完成验收；RTX 2060 6GB 尚未实机验证。本版是可试用的完整离线预发布包，不保证所有电脑或所有录音都能得到理想声音。

这是解压即用包，没有安装/卸载向导。删除软件目录前请备份自己的 `data`。若要完整校验解压文件，在本目录运行 `环境检查.cmd --deep`。
