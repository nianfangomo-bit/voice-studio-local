# 声线工作室 · Windows 本地配音

版本：`v0.2.0-alpha.1`，2026-10-31。当前公开交付目标仍是源码预发布版；已构建独立离线候选目录并完成切分转写测试，**尚未达到完整离线安装包的发布门槛**。

基于 GPT-SoVITS 的中文工作台，使用 Codex 辅助开发。与 OpenAI、GPT-SoVITS 作者没有官方隶属或认证关系。

## 当前能做什么

- 导入兼容声线，在本机生成中文配音；逐句试听、修改、重做。
- 生成完整 WAV、句级 SRT、时间线及版本化交付包。
- 直接选择原始录音，本地切分转写、逐段试听校对，再进行 v2Pro 微调；也支持导入已有 PCM WAV 与 `.list`。
- 保存训练候选声线，试听确认发布，之后重复使用。
- 本机任务队列、日志、失败状态、历史成品保留。
- 新项目优先使用已发布声线，不因新增导入版本而自动切换。

## 下载前必须知道

当前包不带 Python 运行环境、GPT-SoVITS 引擎及基础模型，不带作者个人声音和训练素材。需要可信的、与本版兼容的 v2Pro Windows 整合包。当前没有自动下载器，不能把 GitHub 的 Source code.zip 当成完整安装包。

本版仍需要系统 Python（带 tkinter）运行启动器。启动后选择整合包的运行时，再在环境设置里指定引擎和 FFmpeg。旧配音核心已随包提供，设置中的“旧配音工作流”选择本包 `app/legacy`，无需作者电脑的目录。

入口：`app/启动.cmd`。不要在压缩包内直接运行；先解压到可写目录。不要发布或分享运行后产生的 `app/data`。

## 测试与版本管理

发行以 Git 标签和 GitHub Releases 为准；alpha 版本不承诺稳定兼容。升级前备份 `app/data`，不要用新包覆盖数据目录。每次交付提供文件清单与 SHA-256，不覆盖同版本资产；任何修复增加版本号。

本包提供 `app/tests/test_studio.py` 和 `app/tests/voice-selection.test.mjs`。训练与推理需要真实模型及授权素材，单元测试不替代完整功能验收。

开发者重建界面：在 `app` 下安装 `package.json` 指定依赖后执行 `npm run build`。普通使用无需重新构建；包内已有页面。`tested-environment.json` 记录开发机已验证的主要版本，但不是完整依赖锁。运行根目录 `python build-release.py` 可生成白名单源码包及 SHA-256 校验文件。
