# 声线工作室 · Voice Studio

**v1.0.2-rc.1 · Windows 本地中文配音工作台 · 异机验收候选版**

**完整离线包包含 Python、GPT-SoVITS、训练/配音基础模型、中文转写和音频工具。** 新候选版用于另一台电脑的安装和训练验收，尚未完成异机和完整训练验证，不冒用旧版的验收结果。详见 [候选版下载说明](docs/1.0.2离线候选下载.md)。旧版的实装、训练与字幕记录保留在 [1.0.1 验收记录](docs/offline-final-acceptance.json)，仅适用于旧包。

用自己的录音训练一个声线，以后输入文字就能生成配音和字幕。录音需要你有使用授权；自动转写后仍要自己听一遍、校对文字。

## 它能做什么

- 本地录音导入、切分、中文转写、人工校对及 GPT-SoVITS v2Pro 微调。
- 导入兼容声线，逐句试听、修改、重做，保存历史成品。
- 输出完整 WAV、句级 SRT、分段音频、时间线和交付 ZIP。
- 候选声线试听后发布，后续重复使用；本机任务队列及日志。

1.0.2-rc.1 是本软件的候选版本号，引擎兼容目标仍为 GPT-SoVITS v2Pro，不改变原有界面与配色。

## 已有引擎的历史软件包（进阶用法）

以下是旧软件包的外部引擎启动方式。使用最新完整离线包的普通用户不需要执行这些步骤，直接按新手说明启动即可。

1. 下载 1.0 软件包及对应 .sha256，校验后解压到新的可写目录。
2. 运行 app/启动.cmd。外部引擎模式首次启动需要系统 Python（含 tkinter）；按启动器提示选择兼容引擎的 Python 运行时。保持旧环境依赖不变。
3. 在“更多工具 → 环境设置”连接引擎、FFmpeg；旧配音工作流目录选择本包 app/legacy。
4. 在“训练工作台”导入已授权录音，整理并校对后训练。也可在“我的声线”导入可信兼容模型。
5. 声线验收后在“开始配音”输入文案，先试听首句，再生成全文，下载音频与字幕。

现有数据不要被新版覆盖。具体升级步骤见 [1.0 发布说明](docs/1.0发布说明.md)。

## 开发与版本管理

版本以根目录 VERSION、app/package.json 和不可移动的 vX.Y.Z 标签对应；详见 [版本管理规则](docs/版本管理.md)。构建页面后运行 python build-release.py 产生白名单软件包、文件清单和 SHA-256。脚本拒绝覆盖同版本资产。发布时保留旧版本和变更记录。

界面依赖固定在 app/package.json；tested-environment.json 记录已验证环境。开发者在 app 下安装依赖后执行 npm run build，普通用户使用包内已构建页面。
