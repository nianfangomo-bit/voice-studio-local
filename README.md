## 它能做什么

- 本地录音导入、切分、中文转写、人工校对及 GPT-SoVITS v2Pro 微调。
- 导入兼容声线，逐句试听、修改、重做，保存历史成品。
- 输出完整 WAV、句级 SRT、分段音频、时间线和交付 ZIP。
- 候选声线试听后发布，后续重复使用；本机任务队列、中断恢复与日志。

当前候选版本号为 `1.0.3-rc.3`，引擎兼容目标仍为 GPT-SoVITS v2Pro，保持原有绿色工作台配色。

## 已有引擎的历史软件包（进阶用法）

以下是旧软件包的外部引擎启动方式。使用最新完整离线包的普通用户不需要执行这些步骤，直接按新手说明启动即可。

1. 下载 1.0 软件包及对应 .sha256，校验后解压到新的可写目录。
2. 运行 app/启动.cmd。外部引擎模式首次启动需要系统 Python（含 tkinter）；按启动器提示选择兼容引擎的 Python 运行时。保持旧环境依赖不变。
3. 在“更多工具 → 环境设置”连接引擎、FFmpeg；旧配音工作流目录选择本包 app/legacy。
4. 在“训练工作台”导入已授权录音，整理并校对后训练。也可在“我的声线”导入可信兼容模型。
5. 声线验收后在“开始配音”输入文案，先试听首句，再生成全文，下载音频与字幕。

现有数据不要被新版覆盖。具体升级步骤见 [1.0 发布说明](docs/1.0发布说明.md)。

## 已验证与边界

当前 `1.0.3-rc.3` 源码候选：通过完整自动化回归（Python 套件 + 6 项前端检查），覆盖任务异常恢复、跨重启孤儿进程隔离、训练前依赖/脚本/模型/CUDA 运算检查及离线打包清单核验。`1.0.3-rc.3` 最终离线安装包在干净 Windows 电脑上的断网安装、训练、配音与导出仍待验收；RTX 50 系需单独的 CUDA 12.8 兼容环境，不包含在 CUDA 11.8 包内。

过往记录（1.0.1 / 1.0.2-rc.1 / 1.0.3-rc.2 本机 3080 演示与同机实装）均仅代表对应历史版本，不能替代 `1.0.3-rc.3` 最终包异机验收。字级字幕、MP3、固定文件夹自动发送到剪辑、读音词典仍未实现。现在输出的是句级 SRT，不是逐字对齐或字幕烧录。安装器未签名，不承诺所有机器或任意素材的效果。

## 开发与版本管理

版本以根目录 VERSION、app/package.json 和不可移动的 vX.Y.Z 标签对应；详见 [版本管理规则](docs/版本管理.md)。构建页面后运行 python build-release.py 产生白名单软件包、文件清单和 SHA-256。脚本拒绝覆盖同版本资产。发布时保留旧版本和变更记录。

界面依赖固定在 app/package.json；tested-environment.json 记录已验证环境。开发者在 app 下安装依赖后执行 npm run build，普通用户使用包内已构建页面。

### 运行测试

仓库根目录的统一入口会跑完整 Python 套件和前端检查，并保留实际退出码：

```powershell
pwsh -File .\run-tests.ps1 -Python "F:\VoiceStudio-install-20261117-rc1032\engine\runtime\python.exe"
```

也可以直接运行 `run-tests.cmd -Python "<python.exe>"`（Windows PowerShell 自带环境可用 `powershell -NoProfile -File .\run-tests.ps1`）。也可以先用 `VOICE_STUDIO_PYTHON` 指向已验证的 Python，或不带参数使用 PATH 中的 `python`。退出码 0 表示全部通过；非 0 表示失败。
